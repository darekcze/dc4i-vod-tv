# 1.2.20 draft — offline EPG foundation (not released)

Canonical scope: [#20](https://github.com/darekcze/dc4i-vod-tv/issues/20), roadmap #17.
Production stays at 1.2.19. The integration loads local metadata code without changing the app ID,
touching profiles/playlists/history, fetching a feed or publishing a cache.

## Implemented
- Local, metadata-only XMLTV normalization with explicit source/fetch provenance.
- UTF-8 input only, 2,000,000-byte bound, 20,000 programme/1,000 channel limits,
  depth 16/node 200,000 bounds; malformed XML fails atomically. DOCTYPE/entities
  and compressed input are rejected. There is no decompression or network path.
- Complete second-resolution timestamps with numeric offsets; missing offset
  defaults to UTC. Abbreviated times/missing or reversed end times are skipped
  and counted, not filled with invented durations. Both DST transitions tested.
- Exact duplicates collapse; conflicting channel IDs are quarantined. Explicit
  XMLTV IDs map channels; unique normalized names/aliases are suggestions only.
  HD/time-shift distinctions remain; ambiguous candidates are not auto-selected.
- Metadata whitelist drops arbitrary account/URL fields. Text is still untrusted
  source content: arbitrary local imports must never be assumed safe to publish.
- Bounded memory-only cache (four sources default), five-minute freshness and
  one-hour stale allowance. Partial updates cannot replace existing snapshots
  or renew their timestamp. Older/future/invalid snapshots are rejected; returned
  data is cloned. Timeline queries are half-open and limited to ten days.
- XMLTV editorial ratings remain unverified source values, never TMDB scores.
  Original language does not verify audio/subtitle tracks; playback stays false.
- Standalone synthetic browser preview with deterministic clock, fresh/stale/
  expired controls, inline-hash CSP and no external resources or connections.

## Reproduce
Run `python3 scripts/test_xmltv_metadata.py`, `node scripts/test_rich_epg.mjs`
and `node scripts/test_epg_fixture.mjs` from the repository root. Generate the
preview with `python3 scripts/render_epg_fixture.py --output /tmp/epg-preview.html`
(output must not exist). The controller test uses a VM, not a real browser.

## Guide/details integration increment
The build now loads the local metadata model and adapter. The guide displays
freshness, partial status and source labels for an explicitly accepted local
snapshot, using exact XMLTV IDs only; provider EPG remains the fallback and its
freshness is labeled unknown. Details shows text-only local title candidates as
unverified matches, plus provider provenance. Audio/subtitle tracks remain
unverified. These labels describe the snapshot at render time. Existing provider
play/reminder actions and guide channel playback are unchanged; local metadata
adds no actions. There is no public loader or import UI: acceptLocal is an
in-memory adapter boundary for normalized, locally supplied snapshots.

Run `node scripts/test_epg_metadata_ui.mjs` for the real renderer's VM contract
checks (not browser layout proof). Duplicate identical channel definitions now
collapse in direct cache inputs, matching the importer; conflicts stay quarantined.
