# DC4I VOD TV 1.2.19 | IPTV Channel Guide

Release date: 2026-10-25

## Highlights
- Dedicated IPTV guide screen modeled on familiar TV guide navigation: real Xtream channel groups, channel rows with logos, and a focused program-details pane.
- Now and Next programs, current program title and description, start/end time, and visual progress indicator based on Xtream EPG `get_short_epg`.
- All Channels and per-profile Favorites groups, favorite toggle, per-profile last channel/group selection, Watch and Back actions using the existing Xtream player.
- D-pad and Page Up/Down navigation; tested responsive full-HD layout without pane overlap.
- On-demand EPG with 320ms focus debounce, 5-minute cache and a one-at-a-time provider request queue, reducing pressure on single-connection Xtream accounts.
- Configured account screen remains accessible, with focus returning to the IPTV guide on Back.
- All 1.2.18 personalized recommendation preferences, installed application ID, the owner's playlists and other app features remain available.

## Verification
- Node unit tests: grouping, missing logos, favorites, Now/Next, progress, queue and EPG TTL: passed.
- Chromium 1920x1080: guide navigation, real-label groups, favorites and returning from configuration: passed.
- Chromium regression: personalized recommendations, profiles, TMDB, search, Xtream and other app sections: passed.
- IPK, web manifest, package SHA-256 and preservation of all 32 unrelated Homebrew apps: validated during release.
- Published to `lg.darc.dev` and installed as an in-place update on LG. As requested, no launch, TV remote test, or physical playback test.

## Limitations
The guide uses provider EPG where available. EPG.ovh enrichment, full timeline, confirmed CatchUp, continuous timeshift, DVR and background system notifications are planned separately. LG may intercept CH+/- hardware buttons. The D-pad path is supported.
