## Minimal secure browser repair — environment maintainer only

The installed `/usr/lib/chromium/chrome-sandbox` is mode 4755 but owned by
`nobody:nogroup`. Chromium's setuid sandbox helper requires the trusted packaged
helper to be root-owned, with its vendor-prescribed mode, in a container whose
policy permits the sandbox. Provision/reinstall the trusted Chromium package in
the environment image with correct ownership (root:root, 4755 for this helper),
and validate sandboxed Chromium as the normal non-root worker. The worker must
not change ownership/modes, add `--no-sandbox`, disable AppArmor/seccomp, or grant
itself capabilities. Correct ownership is necessary for the observed error;
further container namespace restrictions may still need maintainer diagnosis.
No production secrets are needed to validate the offline browser fixture.
