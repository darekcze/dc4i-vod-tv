# 1.2.25 draft — official weekly chart links (partial, not released)

Canonical #25 partial fallback. Production remains 1.2.19. Settings offer four
allowlisted official Netflix weekly chart links: global/Poland and films/TV.
Poland is the default. Selection is profile-scoped, with confirmed-write feedback.
Unsupported choices cannot launch an arbitrary URL. No copied rankings, images,
iframe, scraping, background requests, guessed API, feed or public cache.

Opening is explicit via the webOS browser launch service. Desktop/non-webOS
opening is unavailable in this adapter. A positive launch response means only
that the browser accepted the request; page load/content remains unverified.
Failure, exceptions and an eight-second confirmation timeout have generic
feedback without raw errors. Duplicate pending launches are suppressed; closing
the panel invalidates late callbacks. Returning focus restores the selected
control when this view is still active. No unsolicited browser launch occurs.

The panel labels official weekly links separately from TMDB popularity/trending
estimates; neither TMDB scores nor recommendation match scores are represented
as Netflix rankings. Existing TMDB retrieval is unchanged. feedEnabled=false and
rightsStatus=unverified: no integrated verified-feed acceptance is claimed.
