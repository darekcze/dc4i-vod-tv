# 1.2.26 draft — observed native playback (partial, not released)

Canonical #26. Production remains 1.2.19. Native Xtream video sessions can record
local per-profile progression; opening details, playing events alone and external
app handoffs never establish viewing. No stream URL, account, password or title
is stored in playbackLearningV1. Existing opened-history storage is unchanged.

Progress requires foreground visibility/focus and adjacent monotonic timeupdate
samples bounded by wall time (maximum15-second gap). Pauses, seeking, buffering,
background transitions, error/end and profile change break continuity. Unique
media intervals prevent repeated segments within a session inflating duration.
At least30 observed seconds produces partial; ended with at least90% unique
coverage of a known finite duration produces completed. Skipping to the end is
not completion. Unknown/live duration cannot be complete. High-speed or sparse
updates conservatively undercount. Crash before a boundary save can lose progress.

Save on pause/background/stop/end/error uses confirmed readback. Strict storage
reads distinguish absent from corrupt/unreadable values. At most150 session
records; corrupt entries are not replaced. Disabling learning stops new saves and
use in ranking. Clearing this separate history invalidates active-session writes.
Listeners are removed before rebinding and on stop. Profile changes cannot write
observations into another profile.

Matched TMDB detail-to-native paths carry genre IDs (episodes inherit series
genres); direct native entries without matched metadata have no genre affinity.
Observed partial/completed signals augment existing genre affinity, with a bounded
same-weekday/hour contribution; existing rating/favourite/evening rules remain.
Opens remain distinct signals, never converted to watches. Unknown external player
progress remains unknown. Session observations are best-effort, not telemetry proof
against tampering or a complete watch-history service.

Audio/subtitle evidence is read only from runtime media track lists; text tracks
must be subtitles/captions. Original language, country and [PL] labels do not
establish tracks. The policy helper returns unknown without relevant evidence.
English audio plus Polish subtitle availability requires both exposed lists;
Polish dubbing remains unknown because a language tag cannot prove dubbing.
This does not claim a released strict audio filter, actual track selection,
external-player track reporting or verified playback on LG.

Tests use synthetic injected media events and storage only. Real browser/remote,
media timing, track-list support, provider/player and device acceptance remain
open alongside independent review and production release gates. No real stream,
account, credentials, TV contact, merge or deployment.
