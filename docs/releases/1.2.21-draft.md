# 1.2.21 draft — Home rail contracts (not released)

Canonical issue #21, stacked on #20. This first increment is a pure model; it is
not yet loaded into Home. Production stays1.2.19; no data/profile migration.

Implemented: validated enabled sections and stable row order; now/later today/
coming days/missed today/missed week buckets with local calendar/DST boundaries;
film/series/favourite/Sci-Fi/Reality/Family sections using the existing deterministic
profile ranking and explanations. TMDB title cards attribute ratings. Airings
are chronological metadata only, always playable:false, never verified archives.
No new API requests, public cache or provider credentials.

A cold-start cache port accepts existing per-profile read/write functions. It
retains at most300 whitelisted TMDB metadata entries, default1h freshness plus
24h stale allowance. It contains no URLs, artwork URLs, credentials or action
history. Corrupt, oversized, future or expired entries return missing. Binding
the port to TV.store and displaying cache freshness are pending UI work.

- `TZ=Europe/Warsaw node scripts/test_home_rails.mjs`
- `node scripts/test_recommender.mjs`
