# 1.2.22 draft — archive capability contracts (not released)

Canonical issue #22. This increment does not provide verified provider CatchUp
or a real timeshift buffer. Production stays1.2.19. No provider or LG was contacted.

The existing archive path built a credential-bearing timeshift URL from an EPG
archive flag and attempted playback. The draft replaces that unverified archive
attempt with an explicit capability boundary. Past entries now show CatchUp
unverified/unavailable; Details no longer exposes an archive playback button based
solely on has_archive. Live channel playback and future reminders retain their
existing branches. Account, playlist and profile/history storage are untouched.
The default UI adapter has NO transport and performs NO probe/network operation.

An injected, dependency-free controller provides unavailable/unverified/verifying/
ready/starting/playing/failed/stopped states. Runtime proof requires explicit
provider-enabled, verified media type and started-playback evidence from the
adapter; flags alone cannot authorize play. Evidence expires after120s. Verification
and play have bounded deadlines; stop cancels pending deadlines, invalidates late
results and calls adapter cleanup. Generic failure codes never expose raw transport
errors, URLs or credentials. The model forwards only opaque provider/stream IDs
and UTC programme bounds; a future authorized transport must keep credentials in
its private closure and honor stop/cancellation.

Pause/seek require current proof plus adapter-reported finite seekable ranges and
measured buffer bytes. Default budgets120s/32MiB, configurable only up to300s/64MiB;
non-finite targets, gaps, missing measurements and over-budget buffers fail closed.
This validates controls against reported bounds; it does not allocate or prove a
bounded webOS buffer. Actual byte measurement, codec, permissions and seeking are
unimplemented runtime adapter gates. A transport returning synthetic evidence in
tests is not verification of a real provider.

Tests: test_archive_capabilities.mjs exercises flags, verification, disabled/
unsupported providers, deadlines, cancellation/late callbacks, generic failures,
proof expiry, pause/seek and buffer bounds. test_archive_integration.mjs executes
the actual generated playEpg function and proves live/reminder branches stay,
past entries call no media transport, and PL/EN labels are honest.

Remaining: independent review, actual sandboxed browser/remote QA, authorized
provider/media verification, real measured buffer adapter, production packaging,
release checks and applicable device acceptance. No merge, deployment, paid
runner, secrets transfer or security changes. Earlier #20/#21 gates remain open.

## Next offline-safe #23 boundary
Pure scheduling, overlap/conflict policy, idempotent job state transitions,
quota/retention calculations and recovery contracts can be tested with an injected
in-memory fake backend. No storage/backend is selected or written. Real DVR needs
specific backend/storage authorization, quotas/rights, actual recording output and
successful playback after restart; a manifest or synthetic file is not evidence.
