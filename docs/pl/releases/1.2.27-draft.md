# 1.2.27 — projekt: kopia ustawień i audyt zapisu (bez wydania)

Produkcja pozostaje1.2.19. Częściowy zakres #27, bez akceptacji urządzenia/wydania.
Eksport/import tekstu obejmuje wyłącznie układ Home, preferencje przypomnień oraz
region/kategorię rankingów. Bez kont, haseł, playlist, historii, tytułów, strumieni,
cache i przeglądania wszystkich kluczy. Eksport pomija nieznane pola; import
odrzuca nieznane sekcje/pola, inną wersję schematu i dane ponad16KiB.

Po wklejeniu JSON użytkownik wybiera sekcję, sprawdza podgląd i stosuje zmianę.
Edycja/zamknięcie/zmiana sekcji unieważnia podgląd. Zapis sprawdza bieżący profil
i poprzednią wartość, aby wykryć równoległe zmiany. Jedna operacja zapisuje jeden
klucz; nieznane pola celu są zachowane. Cofnięcie jest tylko w pamięci tej sesji,
tego profilu i przy niezmienionej wartości. Brak atomowego odtworzenia wielu
kluczy, automatycznej migracji i cofania po awarii. Aby zachować kopię, skopiuj
wyeksportowany tekst. Brak potwierdzenia zapisu nie jest sukcesem.

Home blokuje nadpisanie nieczytelnego układu; uszkodzony cache jest pomijany bez
ukrywania świeżego katalogu. Otwarcie tytułu nie nadpisuje uszkodzonej historii;
czyszczenie wymaga potwierdzenia. Przewodnik odczytuje preferencje po otwarciu,
chroni nieczytelne dane i potwierdza zapis ulubionych przed zmianą ich stanu.
Czytniki przypomnień/rankingów/odtwarzania pozostają ścisłe. Nieczytelne ogólne
ustawienia profilu blokują personalizację/uczenie i nadpisanie ustawień. Brak
klucza nadal oznacza poprawne ustawienia pierwszego uruchomienia. Bez migracji
kont, profili i playlist.

Test obciążenia Node: pięć przebudów2000 tytułów/20000 zdarzeń EPG, maks20 kart
w wierszu/11 wierszy, cache300 i odrzucanie za dużych danych. Testy odtwarzacza
sprawdzają usuwanie słuchaczy i granice profilu/czyszczenia. To nie pomiar TV
ani nocny test ciągły. Przeglądarka, pilot/pole tekstowe, limit pamięci/reload,
LG i rzeczywiste źródła nadal wymagają dowodów.

Cofanie: PR-y nie są scalone, produkcja bez zmian. Import można cofnąć w tej
samej sesji albo ponownie zaimportować wcześniej skopiowaną sekcję. Uszkodzone
dane pozostają do autoryzowanego odzyskania. Przyszły rollback wydania wymaga
zweryfikowanego kompletu manifest/IPK i zachowania ID/danych. Bez sekretów,
kontaktu z TV, zmian sandboxa, rzeczywistego DVR, scalania i publikacji.
