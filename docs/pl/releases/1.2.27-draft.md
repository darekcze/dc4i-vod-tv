# 1.2.27 — projekt: kopia ustawień i audyt zapisu (bez wydania)

Produkcja pozostaje1.2.19. Częściowy zakres #27, bez akceptacji urządzenia/wydania.
Eksport/import tekstu obejmuje wyłącznie układ Home, preferencje przypomnień oraz
region/kategorię rankingów. Bez kont, haseł, playlist, historii, tytułów, strumieni,
cache i przeglądania wszystkich kluczy. Eksport pomija nieznane pola; import
odrzuca nieznane sekcje/pola, inną wersję schematu i dane ponad16KiB.

Po wklejeniu JSON użytkownik wybiera sekcję, sprawdza podgląd i stosuje zmianę.
Edycja/zamknięcie/zmiana sekcji unieważnia podgląd. Zapis sprawdza bieżący profil
i poprzednią wartość, aby wykryć równoległe zmiany. Jedna operacja zapisuje jeden
klucz; nieznane pola celu są zachowane. Cofnięcie jest tylko w pamięci tej sesji,
tego profilu i przy niezmienionej wartości. Brak atomowego odtworzenia wielu
kluczy, automatycznej migracji i cofania po awarii. Aby zachować kopię, skopiuj
wyeksportowany tekst. Brak potwierdzenia zapisu nie jest sukcesem.

Home blokuje nadpisanie nieczytelnego układu; uszkodzony cache jest pomijany bez
ukrywania świeżego katalogu. Otwarcie tytułu nie nadpisuje uszkodzonej historii;
czyszczenie wymaga potwierdzenia. Przewodnik odczytuje preferencje po otwarciu,
chroni nieczytelne dane i potwierdza zapis ulubionych przed zmianą ich stanu.
Czytniki przypomnień/rankingów/odtwarzania pozostają ścisłe. Nieczytelne ogólne
ustawienia profilu blokują personalizację/uczenie i nadpisanie ustawień. Brak
klucza nadal oznacza poprawne ustawienia pierwszego uruchomienia. Bez migracji
kont, profili i playlist.

Test obciążenia Node: pięć przebudów2000 tytułów/20000 zdarzeń EPG, maks20 kart
w wierszu/11 wierszy, cache300 i odrzucanie za dużych danych. Testy odtwarzacza
sprawdzają usuwanie słuchaczy i granice profilu/czyszczenia. To nie pomiar TV
ani nocny test ciągły. Przeglądarka, pilot/pole tekstowe, limit pamięci/reload,
LG i rzeczywiste źródła nadal wymagają dowodów.

Cofanie: PR-y nie są scalone, produkcja bez zmian. Import można cofnąć w tej
samej sesji albo ponownie zaimportować wcześniej skopiowaną sekcję. Uszkodzone
dane pozostają do autoryzowanego odzyskania. Przyszły rollback wydania wymaga
zweryfikowanego kompletu manifest/IPK i zachowania ID/danych. Bez sekretów,
kontaktu z TV, zmian sandboxa, rzeczywistego DVR, scalania i publikacji.

Podgląd importu pokazuje bezpieczne wartości przed/po, oznacza brak zmian oraz
brak/błędną wartość. Surowe nieprawidłowe i nieznane pola nie są wyświetlane.
Procedura bezpiecznej weryfikacji: docs/STACK-VERIFICATION.md.

## Rozszerzony import metadanych v2

Dodatkowy przepływ obejmuje dozwolone preferencje profilu oraz historię otwarć /
odtwarzania bez tytułów: identyfikatory TMDB/sesji, czas, gatunki i długość obserwacji.
Bez kont, haseł, URL i nieznanych pól. Lokalne nieznane pola są zachowane. Importowane
obserwacje są oznaczone imported i nie stanowią dowodu rzeczywistego oglądania.
Historia jest łączona po tożsamości, nie zastępowana; przekroczenie150 rekordów jest
odrzucane. Limit wejścia256KiB, dziennika512KiB, maks6 sekcji. Obsługiwany schemat1
preferencji przechodzi do2; nieznane schematy są odrzucane. Migracje testowano na
syntetycznych danych, nie na produkcji.

Import wielosekcyjny wymaga Web Locks; bez tej funkcji pozostaje niedostępny.
Przed zapisem powstaje dziennik tylko dozwolonych metadanych. Pojedynczy zapis
localStorage jest atomowy, cały import nie jest globalną transakcją. Po awarii
odtworzony kontroler cofa niezatwierdzone kroki; zatwierdzony dziennik wymaga
sprzątnięcia. Nieudane cofnięcie zachowuje dziennik do jawnego odzyskania. Zmiana
profilu/konflikt blokuje zapis. Obcy niewspółpracujący zapis nie ma gwarancji
transakcyjnej; konflikt wymaga przeglądu. Nierozwiązany dziennik wstrzymuje właściwe
czytniki i zapis, aby częściowe ustawienia nie sterowały przypomnieniami/uczeniem.
Stary szkic ustawień nie może nadpisać zmienionej wartości bazowej.

Testy obejmują przerwanie każdego zapisu, quota, ponowne uruchomienie kontrolera,
przerwane cofanie, błędny dziennik, profile/konflikty, limity i250 cykli słuchaczy.
Osobna diagnoza przeglądarki: SIGABRT Chromium (sandbox nobody:nogroup4755,
NoNewPrivs1/seccomp/mapa UID); samo prawo własności może nie wystarczyć. Oficjalne
pobieranie Playwright1.62/Headless Shell151 rev1234 odmówione HTTP403 Domain forbidden
na cdn.playwright.dev, bez instalacji przeglądarki. Bez obejścia/powtórzeń i bez
potwierdzenia wizualnego.

Dodatkowy test:10 przebudów150000 syntetycznych rekordów (15000 live), limity
200000 katalogu/20000 EPG, długości pól i bezpieczne słowniki. Pomiar źródłowy
409ms, heap Node93MiB — nie gwarancja TV. Zapisane syntetyczne fixture schematu1/2
sprawdzają migrację. Po imporcie ogólnych ustawień profil wymaga ponownego
uruchomienia aplikacji; rzeczywisty restart pozostaje bramką runtime.

Poprawka prywatności: uczenie/personalizacja sprawdzają ścisłe zapisane ustawienia
oraz pamięć. Zapisane wyłączenie działa natychmiast po imporcie, sprzątnięciu
zatwierdzonego dziennika i cofnięciu, nawet gdy TV.S zawiera stare włączenie.
UI wyjaśnia, że inne preferencje mogą wymagać restartu. Końcowe połączone sekcje
Home/przypomnień/rankingów są walidowane; brakujące wartości pierwszego importu
uzupełniają udokumentowane domyślne. Istniejące błędne niepełne rankingi są
odrzucane i zachowane.
