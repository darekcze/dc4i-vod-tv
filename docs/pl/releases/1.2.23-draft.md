# Szkic1.2.23 — kontrakty DVR offline (nieopublikowane)

Kanoniczne #23, oparte na #22. Produkcja pozostaje1.2.19. Nie wybrano, nie
skonfigurowano ani nie zapisano rzeczywistego backendu/storage. Brak nagrywania
plików, dostawcy/LG, konfiguracji sieci i trwałych uprawnień.

Model przyjmuje przyszłe zadania UTC, niejawne ID/kanały i szacunek bajtów.
Ponowienie tego samego ID jest idempotentne, inne dane pod tym ID są odrzucane.
Konflikty wynikają z rzeczywistej jednoczesności półotwartych przedziałów; limity
obejmują liczbę zadań, równoległość i budżet. Niepewne błędy zachowują rezerwacje
i blokują nowe zadania do wyjaśnienia. Spóźnione starty nie udają pełnego nagrania.

Tylko testy wstrzykują backend w pamięci. Jawne ticki sprawdzają start/finish/
cancel/stat, limity czasu i spóźnione odpowiedzi. Brak automatycznego harmonogramu.
Przyszły adapter musi respektować ID i anulowanie oczekujących operacji. Ogólne
błędy nie ujawniają haseł/adresów; przekazywane są tylko dozwolone metadane.

Migawki należą do wywołującego i nie są zapisywane przez moduł. Odtwarzanie stanu
jest atomowe, odmawia nadpisania istniejących zadań, oznacza przerwane operacje
i nie uruchamia ich ponownie automatycznie. Reconcile potwierdza tylko metadane.
Każde zadanie ma playable:false, a usable zawsze false także dla atrapy backendu.
Retencja tworzy plan, niczego nie usuwa. Budżety symulacji nie wybierają dysku.

Aplikacja dodaje wyłącznie informację PL/EN o niedostępnym DVR. Nie ma backendu,
przycisku nagrywania, interfejsu harmonogramu, timera ani wymaganego serwera.
Zwykłe przeglądanie/EPG/oglądanie na żywo pozostają niezależne. Komunikat jest
wewnątrz aplikacji; nie oznacza natywnego powiadomienia w tle.

Luki akceptacji: autoryzowany wybór storage/backendu, capture/kodeki/prawa,
pomiary, realne nagranie, trwałość po awarii, restart i odtwarzanie; ponadto
przeglądarka/pilot/wydajność, pakiet/katalog/publikacja i odbiór LG. Testy
scheduler/integration używają Map z metadanymi, nie plików mediów. Brak wydania.

Następne #24 może rozszerzyć istniejący dc4iEpgRemindersV1 i TV.toast o limity,
włączanie, ciszę nocną, deduplikację, anulowanie/wygasanie, błędy zapisu i testy
profilu/zegara. Dostarczanie tylko w widocznej aplikacji; brak obietnicy działania
po zamknięciu. Budzenie LG, zadania w tle i systemowe toasty pozostają wyłączone
bez potwierdzenia możliwości platformy.
