# VODTV 1.2.20 offline EPG foundation implementation plan

> **For agentic workers:** Use superpowers:executing-plans and test-driven-development. This increment is authorized for implementation and a draft PR; no merge/deployment.

**Goal:** Prove bounded XMLTV normalization, channel identity, metadata provenance and stale-aware local timeline caching for canonical issue #20.

**Architecture:** A standard-library Python importer transforms explicitly supplied local XMLTV into a versioned metadata-only JSON snapshot. A dependency-free browser/Node module maps channels conservatively and provides bounded in-memory TTL snapshots and timeline selection. No public loader, account data, network endpoint or production version change.

**Tech Stack:** Python 3.12 ElementTree/unittest; existing ES2018 window-module pattern and Node assertions; synthetic XMLTV and deterministic browser preview.

**Spec:** docs/superpowers/specs/2026-10-25-personal-tv-guide-design.md; GitHub #17/#20.

## Global Constraints
- Preserve com.dc4i.vodtv, existing profile/playlist storage and 1.2.19 behavior.
- Do not activate EPG.ovh caching or redistribute its data before rights are confirmed.
- XMLTV editorial ratings are not verified TMDB scores. Original language and source subtitle claims do not verify actual playback tracks.
- Archive metadata never enables CatchUp/DVR. No TV contact, secrets, paid service or sandbox bypass.
- This foundation is an incremental draft, not a completed 1.2.20 release.

## Review Focus
- Autumn repeated wall-clock times and spring changes must retain offset-defined ordering; partial/invalid timestamps must not fabricate durations.
- Conflicting duplicate channel identities must not attach another channel's programme.
- Malformed/truncated XML must fail atomically; valid incomplete rows produce counted diagnostics.
- Expired, partial or out-of-order snapshots must not become silently fresh or erase unrelated channels.
- Unexpected URL/account fields must never enter normalized cache records; metadata never becomes playback authorization.
